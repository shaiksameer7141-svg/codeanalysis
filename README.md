💻 Code Learning Assistant

A browser-based JavaScript learning platform designed to help beginners write, execute, analyze, debug, and test JavaScript code through an interactive interface.

🚀 Project Overview

The Code Learning Assistant provides a simple environment where students and beginner developers can practise JavaScript programming. It combines a code editor, basic static analysis, debugging hints, coding exercises, and an interactive tutorial in one application.

✨ Features

- Code Editor: Write and edit JavaScript code directly in the browser.
- Run Code: Execute JavaScript using a sandboxed iframe.
- Code Analysis: Detect common issues such as unmatched brackets and possible missing semicolons.
- Suggest Fixes: Display suggestions for common coding problems.
- Auto-Fix: Apply basic automatic semicolon corrections.
- Coding Exercises: Practise programming with predefined exercises.
- Exercise Generator: Load a randomly selected exercise.
- Interactive Tutorial: Learn how to use the application step by step.
- Debug Console: Display program output and runtime error hints.
- Test Runner: Check exercise solutions against predefined test cases.

🛠️ Technologies Used

- HTML5 – Application structure.
- CSS3 – Styling and responsive layout.
- JavaScript – Application logic and interactive features.
- DOM Manipulation – Updating interface elements dynamically.
- Iframe Sandbox – Basic isolation for code execution.

⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate "hackathon.html".
4. Open the file in a modern web browser.
5. Start writing and practising JavaScript.

No additional installation or external dependencies are required for the current demo.

⚠️ Limitations

This is an educational demonstration project. Its static analyzer uses simple heuristics and is not a complete JavaScript parser. The code execution environment is a basic sandbox and should not be considered a hardened environment for running untrusted code.
